# Курьерский бот

Каждые 15 минут присылает в Telegram: погоду (Заельцовский район, Новосибирск),
примерную ставку в час и совет, что надеть. Работает на GitHub Actions, компьютер не нужен.

## Telegram Mini App — дашборд курьера

Живое веб-приложение поверх бота: **https://promax-star.github.io/courier-bot/**

React + TypeScript + Tailwind (Vite), исходники в `miniapp/`. Показывает текущую погоду,
прогноз ставки на 12 часов (бар-чарт) и советы по одежде. Статическая сборка лежит в `docs/`
и раздаётся GitHub Pages; перезапуск приложения не требует бэкенда — данные тянет из
Open-Meteo прямо из браузера, логика ставки зеркалит `courier_bot.py` (см. `miniapp/src/lib/courier.ts`).

Пересборка: `cd miniapp && npm install && npm run build` (выход — в `../docs/`).

## Настройка (один раз)

1. Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`), скопируй токен.
2. Узнай свой chat_id: `python courier_bot.py --setup` и отправь боту `/start`.
3. В репозитории GitHub: Settings → Secrets and variables → Actions → New repository secret:
   - `TG_TOKEN` — токен бота
   - `TG_CHAT_ID` — твой chat_id
4. Расписание запустится само; для проверки нажми Run workflow на вкладке Actions.

## Как поменять ставку

В `config.json` поле `base_rate` — базовая ставка платформы в рублях за час
(например, сколько платит Яндекс Еда в обычный час). Множители за дождь, мороз,
вечер пятницы уже внутри `courier_bot.py` (функция `rate_advice`).

## Важно про Actions

- Запуск может запаздывать на несколько минут — это нормально для бесплатного GitHub.
- Если репозиторий 60 дней без коммитов, GitHub отключает расписание
  (придёт письмо). Лечится любым коммитом, например правкой `base_rate`.
- Секреты не видны никому даже в публичном репозитории.
